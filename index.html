Como Funciona a Análise de Produção?

Esta aba calcula de forma inteligente a criticidade de estoque e cobertura para cada produto da fábrica, ajudando o PCP a decidir quais peças devem ser produzidas com prioridade.

📊 Conceitos Principais:

  • Estoque Virtual: Físico + Entradas Previstas - Saídas Previstas. Representa a quantidade real projetada de peças.
  • Cobertura (meses): Estoque Virtual / Média Mensal. Indica quantos meses o estoque atual durará com base no giro de vendas.
  • Prioridade (Prio2): Quanto menor o valor, mais crítica é a situação do produto. Produtos com Prio2 negativo ou menor que a Meta de Cobertura estão em falta eminente.
  • Qtd a Produzir: Recomendação automática de quantas peças produzir para atingir a Meta Cobertura selecionada.

💡 Funcionalidades Rápidas:

  • Slider Meta Cobertura: Ajuste o horizonte desejado (ex: 3 meses). Os contadores de Críticos/Atenção recalcularão na hora.
  • Criar OP: Clique no botão de ação da tabela para preencher e abrir automaticamente o formulário de Nova Ordem de Produção com o modelo e a quantidade recomendada.
  • Sincronizar Cobertura: Importe a planilha CODAN atualizada para atualizar os estoques e rastreios.
  • Exportar Excel: Gere um arquivo CSV/Excel apenas com as peças que precisam ser produzidas.
