Como Funciona a Análise de Produção Hélices?

Esta aba calcula de forma inteligente a criticidade de estoque e cobertura para cada produto da fábrica, ajudando o PCP a decidir quais peças devem ser produzidas com prioridade.

📊 Conceitos Principais:

  • Entradas: soma da última quantidade registrada em todas as OPs do mesmo SKU, inclusive quando existirem várias OPs para a mesma hélice.
  • Estoque Virtual: Físico + Entradas - Saídas.
  • Cobertura (meses): Estoque Físico / Média Mensal. Indica quantos meses o estoque atual durará com base no giro de vendas.
  • Prioridade: se Físico < Saídas, recebe -1 (máxima); se Média Mensal < 2, recebe 5; nos demais casos, (Físico - Saídas) / Média Mensal.
  • OP Sugerida: começa com a recomendação automática para atingir a Meta Cobertura, mas pode ser ajustada conforme a decisão do PCP.
  • Stand-by: projeção do estoque após a OP, calculada como Virtual + OP Sugerida.

💡 Funcionalidades Rápidas:

  • Slider Meta Cobertura: Ajuste o horizonte desejado (ex: 3 meses). Os contadores de Críticos/Atenção recalcularão na hora.
  • Adicionar OP: ajuste a quantidade sugerida e clique no botão de ação para abrir a nova ordem com exatamente a quantidade escolhida.
  • Sincronizar Cobertura: Importe a planilha CODAN atualizada para atualizar os estoques e rastreios.
  • Exportar Excel: Gere um arquivo CSV/Excel apenas com as peças que precisam ser produzidas.
